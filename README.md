# 🛡️ LifeShield – Health & Wellness Dashboard

**LifeShield** is a full-stack health and wellness management platform designed to help users monitor their daily health activities, manage vaccination records, track health progress, and maintain important health information in one place.

The application provides a centralized dashboard with user authentication, health tracking, reminders, and data synchronization using a PostgreSQL database.

## 🚀 Features

### 🔐 User Authentication
- User Registration and Login
- Secure user-specific data management
- Logout functionality

### 📊 Health Dashboard
- Personalized health dashboard
- Health profile management
- Daily health statistics
- Weekly health analytics

### ❤️ Daily Health Tracker
- Water intake tracking
- Sleep monitoring
- Daily activity tracking
- Health progress monitoring

### 💉 Vaccination Tracker
- Maintain vaccination records
- Track vaccination history
- Manage upcoming vaccinations

### ⏰ Health Reminders
- Create and manage health reminders
- Track important health activities
- Manage reminder status

### 📈 Health Analytics
- Weekly health progress
- Daily activity summaries
- Assessment history

### 🗄️ Database Integration
- PostgreSQL database
- Spring Boot REST API
- Persistent user-specific data storage
